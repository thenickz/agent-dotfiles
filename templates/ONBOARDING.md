# Onboarding (temporary)

> First thing to run after this project is configured. **Delete this file when done.**

You are the first agent turn in a brand-new project using the agent-dotfiles
knowledge system (`AGENTS.md` + `memory.md` + `architecture.md`). Complete the
steps below, then remove this file.

## Steps

1. Read `AGENTS.md`, `memory.md`, and `architecture.md` at the project root.
2. Analyze the project (structure, runtime/package manager, test/lint/build
   commands, code style from 2-3 representative files).
3. Make the three brain files match the real project — run the
   `scaffold-agents-md` skill, or fill them by hand from the base template:
   - `Commands` must be EXACT and **verified**: run each command to confirm.
   - `Code style`, `Structure`, and `Boundaries` from the actual code.
4. Verify `AGENTS.md` is < 150 lines and every documented command runs.
5. Ask the user only the essentials (project name/description, personal
   preferences, git remote). Decide everything else from the code.
6. Record this bootstrap in `memory.md` (Session Log, today's date).
7. **Delete this file** (`ONBOARDING.md`). If anything blocked onboarding,
   leave it and tell the user what is still missing.
